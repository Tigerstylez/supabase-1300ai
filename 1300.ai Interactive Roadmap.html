Execution Timeline

The execution of 1300.ai is broken into four distinct phases over 36 weeks. Click on each phase below to reveal the specific technical milestones, product deliverables, and core goals.

Weeks 1-4

Infrastructure & Ammunition

Goal: Build the engine and start the "warm-up" clock.

⚙️ Technical Milestones

  • Core Architecture: Stand up Supabase with multi-tenant schema. Design Universal Schema optimized for LLM RAG.
  • Data Engineering (Mika): Deploy Apify scrapers for ~1,200 Pool Targets. Implement Mika Scoring Script.
  • Outreach Stack: VentraIP domains, Google Workspace, Instantly.ai 14-day warm-up.
  • AI Agent: Build B2B verification script (Vapi/Retell). Twilio + n8n for HubSpot sync.

📋 Business & Compliance

  • Legal: Review B2B AI calling compliance.
  • R&D Setup: Initiate Technical Activity Log for 43.5% incentive.
  • Partnerships: Initiate talks with SPASA and Reconciliation WA.
Weeks 5-12

Pool & Spa: The Confidence Builder

Goal: Prove the engine converts and generate initial MRR.

🚀 Technical Milestones

  • Frontend Launch: Deploy findmypool.com.au (Next.js) and build Claim Flow.
  • Avatar Integration: Deploy Unith.ai React component; automate 7-day token refresh.
  • Conversion Tools: Integrate Cal.com for closing calls, Loom for testimonials.

📦 Product Deliverables

  • Founding Tier: Specific UI badges and lifetime discount logic.
  • Mika Dossiers: Automated PDF/Web view generation for sales context.
Weeks 13-20

The AI Market Attack

Goal: Launch interactive AI Directory and LMS pillar.

⚡ Technical Milestones

  • AI Directory: Scrape/score ~2,000 AI companies. Implement interactive listings.
  • The Moat: Develop Mika monitoring engine for LLM visibility (ChatGPT/Claude). Build dashboard.
  • LMS Integration: White-label Coursebox, sync enrollment via Supabase.

🎓 Product Deliverables

  • AI Course: "Couch to AI Use" content production for SMEs.
  • Agent v2: Re-scripted calling agent for the "Leapfrog" cohort.
Weeks 21-36

Depth & Scaling

Goal: Transition from a directory to a white-label platform.

📈 Technical Milestones

  • Vertical Replication: Launch 3rd vertical (e.g., Home Reno) to test schema speed.
  • White-Label Pilot: Build "Organization Admin" view for industry bodies.

💼 Data Room Generation

  • VC Metrics: Aggregate unit economics, R&D tax accruals, cross-pillar conversions.
